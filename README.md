# GameAnalytics

Дипломный проект группы SE-2431: кросс-игровая аналитическая платформа для CS2 и Dota 2 с обнаружением ошибок на основе ИИ.

- Алимов Амир Сакенулы - серверная платформа и интеграции.
- Совет Қажмұрат Ержанұлы - ML и пользовательский интерфейс.
- Сапабек Ерхан Еруланұлы - обработка записей и инфраструктура.

## Работа с репозиторием

Задачи: [YouTrack](https://gameanalytics-se2431.youtrack.cloud/projects/GA/issues).

Изменения готовятся в отдельных ветках с ID задачи, например `GA-2-data-sources`. Коммиты и описание Pull Request должны ссылаться на задачу. Другой участник проверяет PR перед слиянием в `main`. Задача закрывается после выполнения её критериев приёмки.

Репозиторий находится на этапе проектирования. Документы добавляются через PR; наличие документа не означает завершение реализации или проверки интеграции.

## Структура репозитория

- `services/` - будущие сервисы backend и обработки данных.
- `frontend/` - пользовательский интерфейс.
- `migrations/` - миграции баз данных.
- `config/` - шаблоны конфигурации без секретных значений.

## Конфигурация и запуск

Настоящие пароли, токены, ключи API и файлы `.env` не добавляются в репозиторий. Для локальной настройки используется файл `.env.example`.

Запуск приложения пока не реализован. Инструкции запуска будут добавлены после появления исполняемого кода.

## Правила работы

1. Для каждой задачи создаётся отдельная ветка от актуального `main` с ID задачи в названии.
2. Коммиты содержат ID задачи, например: `GA-57: Add repository structure`.
3. Изменения отправляются через Pull Request в `main`.
4. Pull Request проверяет другой участник команды.
5. После одобрения PR сливается в `main`, а задача закрывается в YouTrack после выполнения её критериев.
