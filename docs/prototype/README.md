# Прототип интерфейса GameAnalytics

Кликабельный макет без backend: один файл [`index.html`](index.html), данные вымышленные. Объём MVP — персональный разбор игровых ошибок; античит в объём не входит.

## Как открыть

- Локально: открыть `index.html` в браузере.
- По ссылке: включить GitHub Pages (Settings → Pages → ветка `main`, папка `/docs`), прототип будет по адресу `https://silence99999.github.io/game-analytics/prototype/`. 
- Переключатель «Демо-сценарий» вверху показывает состояния, которые иначе не вызвать.

## Что показано (соответствие критериям первой сдачи)

| Критерий | Где в прототипе |
|---|---|
| Поиск чужого игрока | «Поиск» → Qwerty_77 |
| Публичный профиль | «Поиск» → профиль: только базовая статистика CS2/Dota 2; «Нет данных» отличается от нуля; личные ошибки видны лишь в своём профиле |
| История и карточка матча | «Моя история» → карточка матча |
| Загрузка только из выбранного матча | блок «Разбор ошибок» внутри карточки; общей кнопки «Добавить матч» нет |
| Инструкция скачивания и ссылка | раскрывающийся блок «Как скачать запись» в карточке |
| Статус обработки | выбрать match_ok.dem: «В очереди» → «Разбор записи» → «Поиск эпизодов ошибок» |
| Личный отчёт | «Мой разбор» → отчёт; эпизоды зависят от игры (CS2 и Dota 2 разные): тип, время, наблюдаемые признаки, надёжность сигнала, кнопка «Это не ошибка» |
| Несовпадающая демка | файл other_match.dem |
| Чужой аккаунт | файл not_my_account.dem; в чужом профиле загрузка скрыта |
| Ошибка обработки | файл broken.dem: попытка резервируется, на втором шаге ошибка, резерв освобождается |
| Параллельный запуск | во время обработки одного матча загрузка в другом заблокирована |
| Исчерпанная квота | сценарий «Квота исчерпана» |
| Пустые состояния | сценарии «Пустая история», «Поиск без результатов», пустой «Мой разбор» |
| Мобильная ширина | сузить окно до ~360 px (раскладка перестраивается) |
