# GA-2 — источники данных и границы интеграций

Автор: Алимов Амир Сакенулы, SE-2431. Дата: 19 октября 2026.
Статус: исследование документации; практическая проверка не завершена.
Задача: https://gameanalytics-se2431.youtrack.cloud/issue/GA-2

## Вывод для проекта

Предлагаемая основа: OpenDota для Dota 2 и FACEIT Data API для матчей CS2 на FACEIT. Steam нужен для идентификации и профиля. Premier пока нельзя включать в гарантированный охват: доступная история произвольного игрока без дополнительного подключения не подтверждена. Это предложение для согласования команды, а не результат работающей интеграции.

Выбранный продуктовый сценарий сохраняется: человек открывает существующую карточку матча и вручную загружает запись. Отдельной кнопки создания матча загрузкой файла нет. Следовательно, доступность карточки и проверка соответствия записи — обязательные условия включения источника в MVP.

## Матрица источников

| Источник | Документированный доступ и данные | Ограничения | Решение для проекта |
|---|---|---|---|
| Steam Web API | GetPlayerSummaries принимает ключ и SteamID, возвращает сведения профиля: имя, аватар, URL, состояние видимости [S1] | Метод профиля не является историей CS2. Полученный SteamID сам по себе не доказывает владение аккаунтом | Профиль и внешний идентификатор; подтверждение владения отдельным механизмом входа |
| OpenDota | Профиль `/players/{account_id}`, история `/players/{account_id}/matches`, последние матчи и детали `/matches/{match_id}`; account_id — Steam32 [S2] | Наличие endpoint не гарантирует полноту истории и детальной статистики каждого матча. Доступность конкретных полей, приватных игроков и актуальные квоты проверяются экспериментом | История и карточки Dota 2; отсутствующие данные показывать явно |
| FACEIT Data API | Ключ приложения и Bearer-аутентификация для публичных данных [S3]. История `/players/{player_id}/history`, карточка `/matches/{match_id}`, статистика `/matches/{match_id}/stats`. Схема содержит match_id, game, временные поля, команды, участников, faceit_url, demo_url [S4] | История FACEIT не покрывает Premier. Поля могут отсутствовать; идентификатор FACEIT нельзя напрямую считать идентификатором в демке | Карточки CS2 FACEIT после проверки ключа, реального матча и сопоставления с демкой |
| FACEIT Downloads API | Отдельно одобряемый доступ; resource_url обменивается на подписанный download_url [S5] | Data API key не равен разрешению на Downloads API. demo_url не следует считать общедоступной прямой ссылкой | Не подключать в обязательном MVP; пользователь скачивает запись через доступный ему интерфейс FACEIT |
| CS2 Premier | В рамках проверки не получен воспроизводимый публичный источник полной истории по одному SteamID | Не подтверждены создание карточки без дополнительных данных и связь карточки с записью | Отложить гарантированную поддержку. Проверять отдельным исследованием; не подменять отсутствие API выдуманными матчами |

## Поля внутренней карточки: проектный контракт

Это требования нашего приложения, а не утверждение, что все источники возвращают все поля.

| Поле | Назначение | При отсутствии |
|---|---|---|
| `id`, `game`, `source`, `external_match_id` | Внутренний UUID; игра; источник; внешний ID как строка. Уникальность по `(source, game, external_match_id)` | Карточку не создавать без устойчивого внешнего ключа |
| `started_at`, `duration_seconds` | Время UTC и длительность | `null` и пометка «нет данных» |
| `participants` | Внешний ID игрока с namespace; SteamID64 — строка, если известен | Запрет персонального анализа без подтверждённого сопоставления |
| `result`, `map_or_mode`, `statistics` | Результат и игровые показатели | Показывать только доступное; не заменять пропуски нулями |
| `source_url`, `fetched_at` | Проверяемый источник карточки и время обновления | Не формировать произвольную ссылку из недоверенных входных данных |
| `analysis_available`, `unavailable_reason` | Возможность анализа и понятная причина отказа | Кнопка загрузки недоступна до проверки поддержки |

Общие показатели: число доступных матчей и доля побед на явно указанном наборе. Метрики, специфичные игре, хранить отдельно. K/D, GPM и другие разные величины не объединять в один «универсальный скилл» без отдельной обоснованной методики. Вместе с агрегатом показывать период, размер выборки и источник.

## Проверка загруженной записи — совместно с GA-3

1. Подтвердить Steam-аккаунт пользователя; введённый вручную SteamID не достаточен.
2. Проверить тип, размер и поддерживаемую версию записи; вычислить хеш на сервере.
3. Извлечь идентификаторы и состав игроков. Идентификатор Dota 2 и внешние FACEIT IDs проверять раздельно.
4. Использовать точный проверенный идентификатор матча, если он доступен. Если остаётся только сочетание времени, карты и состава, оценить неоднозначность на реальных записях. Совпадение имени файла или одной карты недопустимо.
5. Не запускать платный/лимитируемый анализ при чужом матче, чужом игроке или неоднозначном соответствии. Сообщить причину; квоту не списывать.

Если GA-3 не подтвердит надёжное сопоставление FACEIT-карточки и демки, для этого источника оставить просмотр статистики; анализ обозначить неподдерживаемым до решения. Это существенный риск обязательного анализа CS2, который нужно согласовать с руководителем, а не скрывать в документации.

## План воспроизводимой проверки

| Проверка | Что сохранить | Условие успеха | Состояние 19.10 |
|---|---|---|---|
| OpenDota: история и детали реального игрока | URL без секретов, время UTC, HTTP-статус, обезличенный JSON и список фактически непустых полей | По ID из истории получена карточка; наличие/отсутствие участников и статистики зафиксировано | Не выполнено: запрос из рабочего окружения завершился ошибкой DNS |
| FACEIT: поиск игрока, история CS2, match и stats | Те же артефакты, без Authorization | ID из истории совпадает с карточкой, проверены участники и статистика | Не выполнено: ключ приложения не предоставлен |
| Steam: публичный/закрытый профиль | Два ответа без ключа и персональных избыточных полей | Реальная разница видимости отражена в UI-контракте | Не выполнено: ключ не предоставлен |
| Premier: возможность получить карточку | Официальная спецификация и реальный ответ либо документированное ограничение | Воспроизводимый путь, совместимый с UX, либо согласованное исключение | Открытый вопрос |
| Демо: верная, чужая, другой матч, повтор | Вывод GA-3 и перечень проверяемых идентификаторов | Нет ложного принятия и двойного списания | Выполняет GA-3 |

Публичный запрос `https://api.opendota.com/api/proMatches` из рабочего окружения не вернул данные: сначала сетевое ограничение, после разрешённого повторного запроса — «Этот хост неизвестен». Открытие URL инструментом веб-поиска распознало JSON, но не предоставило читаемого тела. Поэтому это не считается успешной проверкой и пример ответа здесь не подделан. Ошибка окружения не доказывает отказ сервиса OpenDota.

Для повторения без ключа: запросить `/api/proMatches`, взять реальный `match_id`, затем `/api/matches/{match_id}`. Это проверяет карточку профессионального матча, но не заменяет проверку истории обычного игрока. Следом взять согласованный тестовый `account_id` и проверить `/api/players/{account_id}/matches?limit=5`.

Ключи хранить локально в секретах окружения, не в Git, описании YouTrack или скриншотах. Перед сохранением ответа проверить состав персональных данных. Обработать 401/403 как проблему доступа, 429 как ограничение частоты, временные ошибки — ограниченными повторами. Конкретные квоты запросов закрепить после проверки текущего тарифа, не выдумывать.
