# GA-49 — синтетические заметки для отладки шаблона

## Синтетический профиль R1

- Роль: игрок
- Игра/режим: CS2, FACEIT, иногда Premier
- Длительность в примере: около 17 минут
- Дата: синтетическая, фактическая дата отсутствует

| Тема | Синтетический ответ / сценарий |
|---|---|
| Игровой контекст и частота анализа | Играет 4–5 раз в неделю; пересматривает матчи после поражений примерно 1–2 раза в неделю. |
| Поиск статистики своего или чужого игрока | Проверяет собственные K/D и ADR после серии поражений; ищет статистику соперника перед матчем FACEIT. |
| Используемые сайты и инструменты | FACEIT, Leetify и HLTV для профессиональных матчей. Не хватает объяснения причин проигрыша конкретного раунда. |
| Получение демки | Загружает с FACEIT вручную; файл `.dem.zst` нужно распаковать. Получение Premier-демки через игру представлено как неудобное. |
| Загрузка демки из карточки матча | Ожидает кнопку загрузки в карточке, чтобы не искать файл в папке. |
| Проверка матча и игрока | Сейчас проверяет по имени файла и дате; в синтетическом примере однажды открывает другую демку и замечает это через пять минут. |
| Полезность объяснения ошибок | Интересуют гранаты и позиционирование; общие советы вроде «играй осторожнее» не полезны. Нужен таймкод эпизода. |
| Дополнительные замечания | — |

- Что осталось проверить: насколько часто Premier-демки доступны без ручных шагов.

## Синтетический профиль R2

- Роль: игрок
- Игра/режим: Dota 2, рейтинговые матчи
- Длительность в примере: около 15 минут
- Дата: синтетическая, фактическая дата отсутствует

| Тема | Синтетический ответ / сценарий |
|---|---|
| Игровой контекст и частота анализа | Играет почти ежедневно; разбирает матчи 2–3 раза в месяц, когда прогресс в рейтинге остановился. |
| Поиск статистики своего или чужого игрока | Смотрит статистику по своим героям; открывает профиль другого игрока, чтобы понять его игру. |
| Используемые сайты и инструменты | Dotabuff, OpenDota и встроенный повтор клиента. Не хватает разбора конкретных ошибок вместо общих чисел. |
| Получение демки | Реплей получает через клиент; в примере старый матч недоступен, а способ получить файл вне клиента неясен. |
| Загрузка демки из карточки матча | Предпочёл бы автоматическое получение реплея по ID матча; ручную загрузку считает лишним шагом. |
| Проверка матча и игрока | Доверяет ID матча; для дополнительной проверки хотел бы видеть героя и время матча. |
| Полезность объяснения ошибок | Нужен разбор ошибок с абилками и таймингами ультимейтов, привязанный к конкретному моменту. |
| Дополнительные замечания | Спрашивает, будет ли разбор работать для матчей с друзьями, а не только рейтинговых. |

- Что осталось проверить: срок хранения реплеев и доступность старых матчей.

- Игра/режим: CS2 и Dota 2, казуальные и рейтинговые матчи
- Длительность в примере: около 18 минут
- Дата: синтетическая, фактическая дата отсутствует

| Поиск статистики своего или чужого игрока | Искал статистику друга для сравнения; нашёл общие показатели, но не детализацию. |

| Дополнительные замечания | Важна приватность матчей. |

Возраст и пол, указанные в исходном синтетическом файле, здесь не дублируются: они не нужны для отладки заметок и не являются подтверждёнными данными реальных участников. Не использовать эти профили как доказательство требований или как проведённые интервью.
